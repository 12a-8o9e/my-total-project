# Анализ цен квартир в Москве
Цель проекта: проверить, отличаются ли дисконты и премии первых и последних этажей
в новостройках и на вторичном рынке недвижимости.
## Состав файлов
- Итоговая работа.ipynb — основной notebook с анализом
- moscow_flats_dataset.csv — исходный датасет
- Зависимости.txt — список библиотек для запуска
- outputs/moscow_flats_eda_new.csv — подготовленный результат после обработки
## Как запустить
1 Открыть папку проекта.
2 Убедиться, что файл moscow_flats_dataset.csv лежит рядом с notebook.
3 Установить зависимости из Зависимости.txt.
4 Открыть notebook и выполнить все ячейки сверху вниз.
## Основной результат
В работе рассчитывается цена за квадратный метр, квартиры делятся на первые,
последние и средние этажи, после чего сравниваются медианные значения по группам.
